Private Privacy Report — EastmarkHK HS Code

Internal document for the EastmarkHK HS Code application. This report covers the macOS, iOS and Windows editions.

Status and intended use

This is an internal privacy and data-flow report. It is not the public privacy-policy page. The document is marked noindex / nofollow and should not be published as a public legal notice without review.

Application: EastmarkHK HS Code
Platforms: macOS, iOS and Windows
Report version: 1.0

Summary

  • The HS and NCM databases are stored and searched locally.
  • Search history, quotations and calculator inputs are stored locally when enabled by the application.
  • Cloud AI is optional and is used only when the user requests classification or tax estimation.
  • When cloud AI is used, the product description and classification context are sent to the selected AI provider.
  • The application does not contain third-party advertising tracking.
  • Official NCM and tariff updates can contact Brazilian government services when an update is requested or scheduled.

Optional cloud AI processing

The application can use Anthropic or Mistral for product classification and indicative tax estimation. This processing is optional and requires the user to configure an API key and request the relevant operation.

Depending on the operation, the request can contain:

  • the product description entered by the user;
  • the destination country;
  • candidate HS codes;
  • official Brazilian NCM candidate descriptions, when Brazil is selected;
  • the HS/NCM code used for tax estimation.

The application should not send passwords, payment-card information, private keys or unrelated personal information to an AI provider. Users should avoid including such information in product descriptions.

AI classifications and tax estimates are indicative. They must be verified against the applicable customs tariff, current legislation, official rulings and, where necessary, a qualified customs professional.

Government and official-data connections

The application can download public customs data to update its local databases. The relevant sources include:

  • Brazilian Siscomex / Classif services for NCM nomenclature;
  • Brazilian MDIC / GECEX publications for import-duty data;
  • Brazilian Receita Federal publications for TIPI / IPI data.

These connections are used to obtain public tariff information. The application should not transmit a user's complete search history or quotation database as part of a tariff update.

Local databases and retention

Public HS, NCM and tariff databases are bundled with the application and may also be updated in the platform's application-support directory. User-created data, including history, quotations and calculator values, is retained locally until the user removes it, clears application data, or uninstalls the application.

Local files may be included in operating-system backups. Users who work with commercially sensitive prices or quotations should protect their device account and backups.

Data sharing

EastmarkHK does not sell or rent application data and does not use it for advertising profiling. Data is shared externally only when required for an explicitly requested operation, such as:

  • an AI request sent to Anthropic or Mistral;
  • a public tariff or nomenclature update requested from an official source;
  • platform services required for distribution or purchase processing.

App Store purchase processing, where applicable, is handled by Apple under Apple's own terms and privacy practices.

Security notes

  • Network requests to configured AI and official-data services use HTTPS.
  • API keys must be protected by the platform's credential-storage mechanism wherever available.
  • Local HS/NCM databases contain public tariff information.
  • User quotation and calculator data should be treated as commercially sensitive.
  • Logging must not include API keys or complete confidential quotations.

Before publishing a definitive public policy, the storage mechanism for each platform should be verified in the current release build, particularly for API-key storage and local user databases.

User controls

  • The user can choose whether to use cloud AI.
  • The user can use local HS/NCM search without an AI request when the local databases are available.
  • The user can edit or delete locally stored quotations and search data through the application or operating-system storage controls.
  • The user can remove an API key from the application's settings or credential storage.
  • The user can disable network access at the operating-system or network level, although online AI and database updates will then be unavailable.
